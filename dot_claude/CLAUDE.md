# 개발 규칙

## 테스트
- 테스트를 고치는 대신 비활성화하지 않습니다

## 코드 품질
- 컴파일되지 않는 코드를 커밋하지 않습니다
- 불필요한 코드 제거: 사용하지 않는 Import, 변수, 메서드는 즉시 삭제합니다

## 문서화
- 추측하지 않습니다. 항상 기존 코드로 검증합니다
- 확인이 필요한 내용은 사용자에게 확인을 받습니다
- 다이어그램은 mermaid로 그립니다

## 주석
- 주석은 최소한으로 합니다
- what, how에 대해서 주석을 남기지 않습니다
- why에 대해서만 주석을 남깁니다

## 도구 사용
- 라이브러리 최신 문서 검증: Context7 우선, 실패 시 Fetch/Search 사용
- Notion, Jira, Confluence, Github: MCP 도구 우선 사용

## 커밋
- 커밋 메시지는 한글로 작성합니다
