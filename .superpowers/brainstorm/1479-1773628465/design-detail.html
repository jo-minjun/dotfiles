ws() 함수 설계

tmux 워크스페이스 레이아웃 명령어

사용법

Usage
# 세션 이름 지정
$ ws my-app
# 세션 이름 생략 → 현재 디렉토리 이름 사용
$ ws
# 이미 존재하는 세션이면 attach
$ ws my-app # → tmux attach

레이아웃 (60:40 / 우측 60:40)

tmux workspace
pane 0 — clauded60%
Claude Code
clauded
pane 1 — yazi60%
yazi
파일 탐색기
pane 2 — shell40%
Terminal
일반 쉘

동작 흐름

Flow
1. 세션 이름 결정 (인자 or 현재 디렉토리명)
2. 동명 세션 존재 확인
→ 존재하면 attach 후 종료
3. 새 세션 생성 (detached)
4. 우측 분할 (40%) → yazi 실행
5. 우측 하단 분할 (40%) → 빈 쉘
6. 좌측 pane 선택 → clauded 실행
7. 세션 attach
