# 브랜치 생성

프로젝트의 `.github/BRANCH_CONVENTION.md`에 정의된 네이밍 컨벤션에 맞춰 브랜치를 생성한다.

## 워크플로우

### 1. 컨벤션 파일 확인

프로젝트 루트의 `.github/BRANCH_CONVENTION.md`를 찾는다.

워크트리 내에서 실행 중일 수 있으므로, 원본 레포 루트를 기준으로 탐색한다:

```bash
# 원본 레포의 .git 경로 → 부모 디렉토리가 프로젝트 루트
git rev-parse --path-format=absolute --git-common-dir
```

**파일이 있는 경우**: 읽고 2단계로 진행한다.

**파일이 없는 경우**: 사용자에게 브랜치 네이밍 컨벤션을 질문한 뒤 원본 레포의 `.github/BRANCH_CONVENTION.md`를 생성하고 진행한다.

### 2. 브랜치명 생성

- 사용자의 요청(작업 내용, 티켓 번호 등)을 컨벤션에 맞춰 브랜치명으로 변환한다
- 생성할 브랜치명을 사용자에게 보여주고 확인받는다

### 3. 브랜치 생성

사용 맥락에 따라 적절한 방법으로 브랜치를 생성한다:

**일반 브랜치 생성**:
```bash
git checkout -b <branch-name>
```

**워크트리 생성 중인 경우**: 확인받은 브랜치명을 워크트리 생성 흐름에 전달한다. 워크트리 경로 결정 등 나머지 과정은 워크트리 스킬의 워크플로우를 따른다.
```bash
git worktree add <path> -b <branch-name>
```
