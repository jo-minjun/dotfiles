# 커밋 생성

프로젝트의 `.github/COMMIT_CONVENTION.md`에 정의된 커밋 메시지 컨벤션에 맞춰 커밋한다.

## 워크플로우

### 1. 컨벤션 파일 확인

프로젝트 루트에서 `.github/COMMIT_CONVENTION.md`를 찾는다.

**파일이 있는 경우**: 읽고 2단계로 진행한다.

**파일이 없는 경우**: 사용자에게 커밋 메시지 컨벤션을 질문한 뒤 `.github/COMMIT_CONVENTION.md`를 생성하고 진행한다.

### 2. 변경사항 분석

- staged 변경사항 확인 (`git diff --staged`)
- staged가 없으면 unstaged 변경사항 확인 (`git diff`)
- 변경된 파일 목록과 내용을 분석한다

### 3. 커밋 메시지 작성

- 변경사항을 분석하여 컨벤션에 맞는 커밋 메시지를 작성한다
- 커밋 메시지를 사용자에게 보여주고 확인받는다

### 4. 커밋

- staged가 없었다면 관련 파일을 먼저 staging한다
- 확인받은 메시지로 커밋한다
